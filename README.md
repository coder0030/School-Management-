## Features

### Authentication & Authorization
- Secure login using Spring Security
- Role-based access control (Admin, Teacher, Student, Parent)

### User Management
- Admin can manage Teachers, Students and Parents
- Role assignment and permission control
- Profile update & partial update APIs

### Class & Teacher Management
- Assign teachers to classes
- Class Teacher assignment logic
- Manage class–teacher relationships

### Student & Parent Management
- Add / update / delete students
- Link students with parents
- Manage student details and records

### Fee Management
- Fee structure setup
- Fee payment tracking
- Bulk fee payment support

### Validation & Exception Handling
- Global exception handling
- Custom exceptions for business rules
- Request validation using DTOs

### REST API Architecture
- Clean layered architecture (Controller → Service → Repository)
- DTO pattern implementation
- Standard API response structure
